# AI-First Learning Lab — Web

Interfaz nueva e independiente, hecha con React, TypeScript, Vike, Vite, Tailwind CSS y Bun.

La portada resume el programa, muestra un grupo/proyecto ilustrativo, las cuatro fases y tres skills base. `/skills/` presenta las seis ideas y permite copiar sus prompts.

Los datos de grupo son de muestra. Esta versión no incluye API, autenticación ni persistencia.

```sh
bun install
bun run dev
```

Abre `http://127.0.0.1:3001`.
